# Pipeline CTSD

**CTSD / cathepsin D — NCL10 (neuronal ceroid lipofuscinosis type 10), Parkinson's disease**

CTSD deficiency causes NCL10, an ultra-rare, early-onset condition. CTSD also degrades alpha-synuclein and cleaves prosaposin to saposins, which enhance GBA activity — altered CTSD reduces both synuclein degradation and GBA activity, increasing synuclein aggregation. CTSD is also documented in Alzheimer's-disease literature (amyloid precursor protein / Tau clearance) as field context only, not a NanoERT programme.
